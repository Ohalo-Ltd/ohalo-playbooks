# Frontend

Graph RAG Frontend built with Next.js, TypeScript, shadcn/ui, and TanStack Query.

## Setup

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Run production build
npm start

# Lint
npm run lint
```

## Development

The frontend will be available at http://localhost:3000

API endpoint is configured to connect to the backend at http://localhost:8000
